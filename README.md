# Portfolio Pessoal - Giovanny Lino Tavares de Oliveira

Este é o meu portfólio pessoal desenvolvido com React, TypeScript e Tailwind CSS, com suporte a múltiplos idiomas (Português, Inglês e Espanhol). O site apresenta minhas informações pessoais, habilidades, projetos e contato, com navegação interativa por abas e design moderno com modo escuro.

## Tecnologias Utilizadas

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- shadcn/ui (componentes acessíveis)
- React Router DOM
- Context API para gerenciamento de idioma e tema
- Lucide React (ícones)
- Hospedagem na Vercel

## Funcionalidades

- 🌐 Troca dinâmica entre Português, Inglês e Espanhol
- 🌙 Modo escuro/claro com toggle no navbar
- 📑 Navegação por abas interativas (Sobre, Habilidades, Projetos, Contato)
- 🎨 Background animado e interativo com efeitos de blur
- 📱 Layout totalmente responsivo (mobile e desktop)
- 🔗 Links para GitHub, LinkedIn, email e download do currículo
- ✅ Badge de verificação na foto de perfil

## Como Rodar Localmente

Clone este repositório:

```bash
git clone https://github.com/GiovannyLino/Portfolio.git
```

Entre na pasta do projeto:

```bash
cd Portfolio
```

Instale as dependências:

```bash
npm install
```

Inicie a aplicação:

```bash
npm run dev
```

Acesse o site localmente em `http://localhost:5173`.

## Como Hospedar na Vercel

1. Crie uma conta no [Vercel](https://vercel.com) (se ainda não tiver).
2. Faça o deploy conectando seu repositório GitHub.
3. Configure o framework como **Vite**.
4. Aguarde a build e veja seu site publicado na URL da Vercel.
